### 3. Deploy on Render
- **Option A:** Connect your GitHub repo at render.com — Render will auto-detect `render.yaml`
- **Option B:** Use Render Dashboard → New → Blueprint → Connect repo

### 4. Set Environment Variables (in Render Dashboard)

**API Service (smart-ops-hub-api):**
| Key | Value |
|-----|-------|
| `DJANGO_ALLOWED_HOSTS` | `smart-ops-hub-api.onrender.com` (or your custom domain) |
| `FRONTEND_ORIGINS` | `https://smart-ops-hub-frontend.onrender.com` |

**Frontend Service (smart-ops-hub-frontend):**
| Key | Value |
|-----|-------|
| `VITE_API_BASE` | `https://smart-ops-hub-api.onrender.com/api` |

### 5. Create Postgres Database
- Render will create `smart-ops-hub-db` when you deploy the Blueprint (defined in render.yaml)
- `DATABASE_URL` is injected automatically
